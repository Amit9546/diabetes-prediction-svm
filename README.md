# Diabetes Prediction using Support Vector Machine (SVM)

This repository contains a machine learning project that implements a Support Vector Classifier (`SVC`) using Scikit-Learn to perform binary classification on the standard diabetes dataset.

## 🚀 Project Overview
The goal of this project is to predict diabetes status based on various physiological and diagnostic features (such as age, BMI, blood pressure, etc.). The target variable is converted into a binary classification problem (1 for high risk / output $\ge 150$, 0 otherwise).

## 🛠️ Tech Stack
* **Python**
* **Pandas & NumPy** (Data Manipulation & Preprocessing)
* **Scikit-Learn** (Machine Learning Model & Evaluation Metrics)
* **Jupyter Notebook**
